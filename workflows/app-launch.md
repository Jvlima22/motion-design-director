# App Launch

## Role

Specialization for launching a mobile, desktop or cross-platform application.

Load after:

workflows/product-video-master.md

---

# Launch Objective

An app launch usually needs to create:

AWARENESS
-> DESIRE
-> PRODUCT UNDERSTANDING
-> MEMORY

The exact balance depends on the brief.

A launch film is not automatically a tutorial.

---

# Reveal Strategy

Determine what deserves the reveal:

- app identity
- core interaction
- transformation
- interface
- ecosystem
- new version
- signature capability

Possible structures:

TENSION
-> REVEAL
-> EXPLORATION
-> RESOLUTION

or:

LIFESTYLE / CONTEXT
-> APP
-> INTERACTION
-> RESULT

or:

BRAND PROMISE
-> PRODUCT MOMENTS
-> HERO CAPABILITY
-> END RESOLUTION

---

# Device Context

Use device mockups only when the device adds meaning.

Possible treatments:

- physical device
- floating device
- full-screen UI
- cropped UI
- device-to-UI transition
- multiple devices
- environment + device

Do not trap the entire launch film inside a small phone mockup.

The product must remain readable.

---

# Interaction

Prioritize signature interactions.

Examples:

- onboarding
- gesture
- navigation
- tracking
- creation
- search
- capture
- payment
- completion
- result

Do not demonstrate every navigation step unless comprehension requires it.

---

# Product Identity

A launch should create recognizable visual memory.

Identify recurring anchors such as:

- brand color
- device treatment
- signature motion
- typography
- shape
- UI behavior
- sonic motif

Repetition should build identity, not monotony.

---

# Platform Adaptation

For mobile-first social delivery, combine with:

workflows/social-video.md

Do not simply crop a landscape launch into vertical.

Recompose.

---

# Launch Quality Gate

Before finalizing, ask:

IS THERE A CLEAR REVEAL?

DOES THE APP FEEL LIKE THE HERO?

IS THE PRODUCT REAL AND LEGIBLE?

DOES THE FILM CREATE A MEMORABLE PRODUCT IMPRESSION?

IS EXPLANATION OVERSHADOWING DESIRE?

IS DESIRE OVERSHADOWING UNDERSTANDING?

Correct the imbalance according to the communication goal.
