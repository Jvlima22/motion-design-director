\# Effects Library



\## Purpose



A functional library of effects for professional motion design, SaaS, apps,

software, AI products and technology films.



Effects are not decoration.



Every effect must have a job.



Select effects according to:



COMMUNICATION

→ ATTENTION

→ DEPTH

→ ENERGY

→ CONTINUITY

→ MATERIAL

→ ATMOSPHERE

→ BRAND



Never begin with:



"What effect would look cool?"



Begin with:



"What visual problem must be solved?"



\---



\# 1. Effect Selection Framework



Before adding an effect determine:



GOAL

→ what must improve?



TARGET

→ what receives the effect?



INTENSITY

→ subtle / medium / hero



DURATION

→ momentary / sustained



CONTEXT

→ what else is moving?



READABILITY

→ what must remain clear?



Then select the smallest effect capable of solving the problem.



\---

\# 3. Attention Effects



Purpose:



direct viewer attention.



Examples:



\- scale emphasis

\- spotlight

\- dim surroundings

\- color activation

\- glow activation

\- focus pull

\- pulse

\- underline

\- mask reveal

\- contrast increase



Use when hierarchy needs reinforcement.



\---



\# 4. Spotlight



Isolate an important region through light or contrast.



Useful for:



\- feature

\- metric

\- button

\- AI result



Avoid literal circular spotlights unless style supports them.



Usually a local luminance shift is enough.



\---



\# 5. Surrounding Dim



Pattern:



HERO remains normal



SUPPORT decreases:



\- opacity

\- brightness

\- saturation

\- contrast



Extremely useful for product demonstrations.



Often better than adding a new visual effect to the hero.



\---



\# 6. Scale Emphasis



Temporarily increase scale to establish importance.



Useful for:



\- cards

\- metrics

\- CTA

\- selected UI



Keep UI scale changes controlled.



Excessive scaling makes interfaces feel elastic.



\---



\# 7. Pulse



A brief scale/light/opacity event.



Useful for:



\- active node

\- notification

\- processing step

\- selected state

\- data arrival



One or two pulses are usually enough.



Avoid perpetual pulsing unless it communicates an ongoing state.



\---



\# 8. Focus Pull



Shift visual focus between depth layers.



Possible:



FOREGROUND SHARP

→ BACKGROUND SHARP



or reverse.



Useful for dimensional UI.



Avoid when both layers contain important readable information.



\---



\# 9. Highlight Sweep



A light sweep travels across a surface.



Useful for:



\- logo

\- device

\- premium card

\- product hero



Should be rare.



Too many sweeps create stock-template aesthetics.



\---



\# 10. Depth Effects



Purpose:



create spatial separation.



Examples:



\- parallax

\- Z separation

\- shadow elevation

\- depth of field

\- foreground occlusion

\- perspective

\- atmospheric depth

\- scale depth



Depth must explain hierarchy.



\---



\# 11. Parallax



Move layers at different relative speeds.



Typical relationship:



BACKGROUND

slow



MIDGROUND

medium



FOREGROUND

fast



Useful for:



\- hero shots

\- floating UI

\- spatial dashboard

\- device sequences



Do not use arbitrary independent drift.



\---



\# 12. Z Separation



Move components forward/backward in dimensional space.



Useful for:



\- feature extraction

\- UI explosion

\- architecture

\- hero focus



Preserve interface relationships.



\---



\# 13. Shadow Elevation



Increase shadow/elevation as object moves forward.



Useful for:



\- cards

\- modals

\- feature extraction

\- floating UI



Coordinate shadow with actual spatial movement.



\---



\# 14. Depth of Field



Use blur according to depth.



Useful for:



\- hero device

\- foreground transitions

\- cinematic UI

\- focus changes



Protect readable interface elements.



\---



\# 15. Foreground Occlusion



Place an object close to camera.



Useful for:



\- depth

\- transition

\- composition

\- revealing environment



Possible objects:



\- UI card

\- device edge

\- text

\- geometry



Foreground elements should not randomly block important content.



\---



\# 16. Atmospheric Depth



Reduce:



\- contrast

\- saturation

\- sharpness



for distant layers.



Useful in large spatial systems.



Subtle atmospheric depth often looks more believable than heavy blur.



\---



\# 17. Perspective



Perspective itself is an effect.



Use for:



\- physicality

\- scale

\- cinematic presentation



Reduce during dense reading.



\---



\# 18. Light Effects

\- activation

\# 22. Rim Light

\---



\# 23. Radial Light

\- typography

\# 24. Volumetric Light

\---



\# 25. Environmental Spill

LEVEL 2

\# 108. Anti-Pattern — Effect Soup



Problem:



many unrelated effects stacked together.



Fix:



identify one primary visual mechanism.



\---



\# 109. Anti-Pattern — Glow Soup



Problem:



every edge emits light.



Fix:



define actual light sources and hero states.



\---



\# 110. Anti-Pattern — Particle Soup



Problem:



particles fill empty space without meaning.



Fix:



give particles a role or remove them.



\---



\# 111. Anti-Pattern — Blur Everything



Problem:



blur used as universal cinematic treatment.



Fix:



blur only according to depth, focus, speed or transition.



\---



\# 112. Anti-Pattern — Generic Glitch



Problem:



glitch added because product is "tech."



Fix:



use glitch only when disruption/error/digital instability is meaningful.



\---



\# 113. Anti-Pattern — Permanent Maximum Intensity



Problem:



effects never decay.



Fix:



design:



ENTRY

→ PEAK

→ SETTLE



\---



\# 114. Anti-Pattern — Effect Before Story



Problem:



scene exists to demonstrate an effect.



Fix:



MESSAGE

→ SHOT

→ MOTION

→ EFFECT



\---



\# 115. Anti-Pattern — Effect Hides Product



Problem:



visual treatment makes interface unreadable.



Fix:



reduce effect intensity immediately.

\# 118. Restraint Test



Temporarily disable the effect.



Ask:



Is the shot still understandable?



If NO:



the shot may depend too heavily on effects.



If YES:



ask whether re-enabling the effect meaningfully improves:



HIERARCHY

DEPTH

EMOTION

CONTINUITY

BRAND



If not:



remove it.



\---



\# 119. Creative Director Rule



Never recommend an effect by name alone.



Bad:



"Add particles and glow."



Better:



"Use a low-density traveling pulse along the connection path so the viewer

understands that data is moving from the lead source into the AI qualification

node. Allow the target node to brighten briefly when the pulse arrives."



Always connect:



EFFECT

→ PURPOSE

→ BEHAVIOR

→ RESULT



\---



\# 120. Golden Rule



Effects amplify meaning.



They do not create meaning.



First make the shot communicate.



Then use effects to strengthen:



ATTENTION

DEPTH

ENERGY

CONTINUITY

MATERIAL

ATMOSPHERE



If removing an effect makes the idea clearer,

remove it.
